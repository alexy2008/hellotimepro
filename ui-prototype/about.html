关于 HelloTime Pro

多技术栈对比学习项目 —— 同一款时光胶囊 Web 应用，由若干前后端框架各自实现一遍。 本页只介绍当前正在运行的这一组栈，后端信息从 /api/v1/health 实时上报。

ⓘ 当前前端是 React + TypeScript（示意）；后端通过 :9080 反向代理动态切换，无需重启前端。

前端栈

React

v19 框架

由 Meta 创造的声明式 UI 库，组件化与单向数据流的事实标准

  • 函数式组件 + Hooks，状态与副作用就地表达
  • Fiber 调度器支持可中断渲染，交互优先
  • 19 引入 Actions / use() / React Compiler，自动 memo 化
  • 生态繁荣：Next.js、Remix、React Native 共享同一心智模型

TypeScript

v5 语言

给 JavaScript 加上静态类型的工业级超集

  • 渐进式类型系统，可与现存 JS 无缝混合
  • 强大的类型推断，泛型 / 联合 / 条件类型表达力极佳
  • IDE 支持一流：跳转、重命名、自动导入即时反馈
  • 编译产物即标准 JS，零运行时开销

后端栈 · hellotime-pro v0.1.0

FastAPI

v0.115 框架

基于 Starlette + Pydantic 的现代异步 Python Web 框架

  • 类型注解即文档，自动生成 OpenAPI / Swagger UI
  • 原生 async/await，由 Uvicorn (ASGI) 驱动
  • Pydantic v2 数据校验，性能逼近编译型语言
  • 依赖注入系统简洁强大，路由即接口契约

Python

v3.12 语言

优雅、动态、解释型的通用编程语言

  • 语法简洁接近伪代码，学习曲线平缓
  • 庞大的科学计算与 AI 生态：NumPy / PyTorch / Pandas
  • Type Hints (PEP 484) 让大型项目也保持类型安全
  • asyncio 原生协程，IO 密集任务表现出色

PostgreSQL

v16 数据库

功能丰富的开源关系型数据库，号称"最先进的开源数据库"

  • 完整 ACID + MVCC，强大的查询优化器
  • JSONB / 数组 / 全文检索 / GIS (PostGIS) 一应俱全
  • 逻辑复制、分区表、并行查询
  • 16 版强化逻辑复制并行性能与查询执行

三条硬约束

  • API 同源：所有后端实现同一份 spec/api/openapi.yaml，由契约测试验证。
  • UI 同源：所有前端消费同一份 spec/styles/tokens.css，视觉对齐到像素级。
  • 数据同源：所有后端兼容同一份 spec/db/schema.sql，可通过反向代理热切换。
