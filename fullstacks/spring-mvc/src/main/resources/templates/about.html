About

有些话， 要等一等再说

HelloTime Pro 是一款时间胶囊应用：写下一段话，设定未来某一刻才能开启，封存之后不可修改。它有胶囊广场、AI 代笔、收藏与账号。

它同时也是一个多技术栈对比学习项目的一部分。你正在使用的这一套，由下面的服务端模板与后端技术栈同源实现，并遵循项目统一的 API 契约、数据库 schema 与设计令牌。
