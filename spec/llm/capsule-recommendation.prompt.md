HelloTime Pro 是一个时光胶囊 Web 应用。用户写下一段话，并设置一个未来时刻；时间到达前胶囊上锁，连本人也无法查看；时间到达后才会被开启。现在用户刚打开"创建胶囊"页面，还没想好写什么，需要你给出一组特色主题推荐，激发灵感。

1. title（主题标题）

3. openInDays（建议开启天数）
   - 整数，范围 1～3650，要贴合主题语义

- 其余可自由分布
